# 5.3.0

## API

**[API v5.3.0](https://github.com/moxondev/api/releases/tag/5.3.0)** — Case & JWT.

- Ajout de l'endpoint **[GET /case](/v5/fr/case)** : convertit un texte entre 9 formats de casse avec une tokenisation universelle gérant le split camelCase, `_`, `-`, `.` et les espaces. Formats disponibles : `camel`, `pascal`, `snake`, `kebab`, `constant`, `title`, `sentence`, `upper` et `lower`. Retourne le texte original, le format cible et le résultat converti.
- Ajout de l'endpoint **[POST /jwt](/v5/fr/jwt)** : décode un JSON Web Token sans vérifier la signature. Retourne le header et le payload décodés sous forme d'objets, la signature brute, et un booléen `expired` dérivé du claim `exp` lorsqu'il est présent.
