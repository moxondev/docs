# 5.7.0

## API

**[API v5.7.0](https://github.com/moxondev/api/releases/tag/5.7.0)** — Paquet npm & configuration d'instance.

- Le paquet `@20syldev/api` s'importe désormais directement : `import { evaluate } from '@20syldev/api'` cible la dernière version, `@20syldev/api/server` démarre l'API complète avec toutes ses versions montées, et les déclarations TypeScript sont livrées avec. Les sous-chemins `/v1` et `/v2` pointaient vers des fichiers inexistants — c'est corrigé.
- **[GET /url](/v5/fr/url)** renvoie le port par défaut du schéma quand l'URL n'en précise aucun : `443` pour `https` et `wss`, `80` pour `http` et `ws`, `21` pour `ftp`. `null` reste réservé aux schémas sans port connu.
- Les métadonnées d'instance deviennent configurables — `DOCS_URL`, `REPO_URL`, `INSTANCE_CREATED` — et chaque champ disparaît de **[GET /infos](/v5/fr/infos)** tant qu'il n'est pas renseigné : une instance auto-hébergée n'affiche plus la documentation ni le dépôt de quelqu'un d'autre.
- L'endpoint `/logs` peut être fermé par un jeton, attendu dans l'en-tête `X-Logs-Token` et défini par `LOGS_TOKEN`. Sans cette variable il reste ouvert, comme avant.
- Les journaux ne conservent plus les valeurs passées en paramètre : `?text=secret` est tracé en `?text`. Les jetons de conversation privée et de partie portés dans le chemin sont également masqués.
- `TRUSTED_PROXIES` décrit les sauts de confiance derrière un CDN ou un routeur de plateforme, en blocs CIDR ou via les raccourcis `loopback`, `linklocal` et `uniquelocal`.
- Les réponses d'erreur ne portent plus le lien `documentation` qu'elles incluaient — le corps se limite désormais à `message`, `error` et `status`.
- **Node 22.12** devient le minimum requis, ce qui permet d'utiliser le paquet aussi bien en ESM qu'en CommonJS.

## Documentation

- Suppression du champ `documentation` de tous les exemples d'erreur de la page [Commencer](/v5/fr/), conformément au corps d'erreur allégé.
- Documentation des ports par défaut par schéma sur **[URL](/v5/fr/url)** et correction du champ `port`, qui ne retourne plus `null` dès que l'URL l'omet.
- Mention du caractère dépendant de l'instance des champs `documentation`, `github` et `creation` sur **[Infos](/v5/fr/infos)**, une instance auto-hébergée les omettant si elle n'est pas configurée.
