# 5.0.0

## API

**[API v5.0.0](https://github.com/moxondev/api/releases/tag/5.0.0)** — Evaluate, Matrix, Chart.

- Ajout de l'endpoint **[GET /evaluate](/v5/fr/evaluate)** : évalue des expressions mathématiques de manière sécurisée via un parseur Pratt (sans `eval()`). Supporte les opérateurs `+` `-` `*` `/` `%` `^`, la négation unaire, les constantes `pi` et `e`, ainsi que 14 fonctions intégrées (`sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `abs`, `floor`, `ceil`, `round`, `log`, `log2`, `log10`). Un paramètre `precision` optionnel (0–15) contrôle les décimales. La longueur est limitée à 500 caractères et la profondeur de récursion à 100.
- Ajout de l'endpoint **[POST /matrix](/v5/fr/matrix)** : effectue 8 opérations matricielles sur des matrices jusqu'à 20×20 : `add`, `subtract`, `multiply`, `scalar`, `transpose`, `determinant`, `inverse` et `identity`. Le déterminant utilise l'élimination gaussienne avec pivot partiel ; l'inverse utilise Gauss-Jordan.
- Ajout de l'endpoint **[POST /chart](/v5/fr/chart)** : génère des graphiques SVG (barres, lignes, camembert, donut) à partir de tableaux de données. Supporte couleurs personnalisées, titre, fond, légende et dimensions fixes optionnelles. Définir `mode` à `"data"` retourne les données brutes en JSON plutôt que le SVG. Maximum 20 labels et 5 datasets.
- L'URL de documentation dans les erreurs 404 pointe désormais toujours vers la dernière version au lieu de la version demandée.
