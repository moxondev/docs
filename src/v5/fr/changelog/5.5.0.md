# 5.5.0

## API

**[API v5.5.0](https://github.com/moxondev/api/releases/tag/5.5.0)** — Endpoint Auth & `/latest` toutes méthodes.

- Ajout de l'endpoint **[GET /auth](/v5/fr/authentication#verifier-son-offre)** : vérifie un token Bearer et retourne son `tier` et ses `limits` (`hourly`, `burst`). Sans token, retourne le tier `default` ; un token invalide retourne un `401`.
- La redirection `/latest` fonctionne désormais avec toutes les méthodes HTTP : un `307` préserve la méthode et le corps, donc les requêtes `POST /latest/...`, `PATCH` et `DELETE` sont maintenant correctement redirigées vers la version courante — auparavant, seul `GET` fonctionnait.
- Le paquet npm `@20syldev/api` est désormais générique : l'endpoint personnel `/website` est sorti du cœur vers un système de plugins optionnels, exclu du paquet npm.
- Robustesse interne : correction d'un test temporel non déterministe et passe de formatage.

## Documentation

- Documentation de **[GET /auth](/v5/fr/authentication#verifier-son-offre)** sur la page Authentification : utilisation, champs de réponse, et comportement du tier `default` sans token.
- Ajout d'une note sur la préservation de la méthode et du corps par `/latest` pour les requêtes non-`GET` dans le guide de migration.
- Correction des liens `/v4/` obsolètes entre les pages Authentification et Tarification — les deux auraient dû pointer vers `/v5/`.
- Regroupement des exemples dupliqués (header d'auth, erreur) de la page Tarification sur Authentification, et déplacement de sa note « Aucun token ».
