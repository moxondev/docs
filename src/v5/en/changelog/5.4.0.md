# 5.4.0

## API

**[API v5.4.0](https://github.com/moxondev/api/releases/tag/5.4.0)** — Stability and hardening.

- Fixed **[/address](/v5/en/address)** (street word order for `us`, `uk`, and `de` addresses, e.g. `42 Main Street`) and **[/text](/v5/en/text)** (now correctly writes `soixante et onze` for French 71).
- Hardened crypto modules: **[/otp](/v5/en/otp)** fixes a counter-zero underflow and switches to a timing-safe comparison, **[/symmetric](/v5/en/symmetric)** adds an integrity MAC to CBC mode, and **[/asymmetric](/v5/en/asymmetric)** derives its size limit from the actual key modulus instead of the client-supplied value.
- Fixed compute and rendering modules: **[/evaluate](/v5/en/evaluate)** (unary minus precedence, malformed numbers), **[/matrix](/v5/en/matrix)** (false "singular matrix" from determinant rounding), **[/algorithms](/v5/en/algorithms)** (integer validation for `isprime` and `factorial`), and **[/chart](/v5/en/chart)** (all-zero, single-slice, and single-label data).
- Fixed **[/barcode](/v5/en/barcode)** (inverted rendering, EAN-8 check digit), **[/jwt](/v5/en/jwt)** (rejects non-object `header`/`payload`), **[/case](/v5/en/case)** (rejects separator-only input), **[/chat](/v5/en/chat)** (session eviction, private room pruning), and **[/tic-tac-toe](/v5/en/tic-tac-toe)** (player registration, casing, cleanup timers).
- Hardened GET routes against array-valued query parameters, NaN inputs, and missing modules; the error handler is now registered after routes, and unknown endpoints return a structured **JSON 404** instead of an HTML page.
- Fixed a rate-limiting off-by-one and evict stale users; the **`/latest`** redirect now preserves the full path and query string.
- Added a large batch of unit and integration tests covering these fixes.

## Documentation

- Documented the country-dependent street word order on **[Address](/v5/en/address)**.
- Added the new `count`/`size`/`width`+`height` NaN-guard errors to **[Address](/v5/en/address)**, **[Avatar](/v5/en/avatar)**, **[Barcode](/v5/en/barcode)**, and **[Cron](/v5/en/cron)**.
- Added the new `factorial`/`isprime` validation errors to **[Algorithms](/v5/en/algorithms)**.
- Clarified that **[Asymmetric](/v5/en/asymmetric)**'s `modulusLength` only applies to `keygen`, and broadened the invalid key format description.
- Updated **[JWT](/v5/en/jwt)** error messages for the new non-object header/payload rejection.
- Added the new separator-only input error to **[Case](/v5/en/case)**.
- Documented unary minus precedence and the new malformed-number error on **[Evaluate](/v5/en/evaluate)**.
- Updated **[Symmetric](/v5/en/symmetric)**'s blob format for the CBC integrity MAC, with a breaking-change note for pre-5.4.0 CBC blobs.
- Added a JSON 404 example to the [Getting Started](/v5/en/) error handling section, and a nested-path/query example for `/latest` to the changelog migration guide.
