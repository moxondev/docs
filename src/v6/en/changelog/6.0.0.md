# 6.0.0

## API

**[API v6.0.0](https://github.com/20syldev/api/releases/tag/6.0.0)** — Identifiers out of URLs, v1–v3 retired, rate limit headers.

- **[GET /captcha](/v6/en/captcha)** now answers in `challenge` mode **by default**: the image comes with a signed token instead of the answer in clear, and its rendering is hardened against automated reading. The historical generator stays available through `?mode=image`, for anyone who needs to read the answer server-side.
- Versions **`v1`, `v2` and `v3`** are retired, along with all the untyped JavaScript they shared. The API now serves only `v4`, `v5` and `v6` — install `@20syldev/api@5.9.0` if you still need an older one.
- **[POST /levenshtein](/v6/en/levenshtein)** moves from `GET` to `POST`: the two strings being compared no longer travel in the URL, and therefore no longer through browser history or the logs of any intermediary.
- Sensitive identifiers leave the URL: `DELETE /chat/:token` becomes **[POST /chat/clear](/v6/en/chat/clear)**, and `PATCH`/`DELETE /tic-tac-toe/:game` become **[POST /tic-tac-toe/play](/v6/en/tic-tac-toe/play)** and **[POST /tic-tac-toe/forfeit](/v6/en/tic-tac-toe/forfeit)**. The `PATCH` and `DELETE` methods disappear from the API entirely.
- Error responses now return `status` as a **number** rather than a string.
- Every response now carries the `X-RateLimit-Limit`, `X-RateLimit-Remaining` and `X-RateLimit-Reset` headers, and a `Retry-After` accompanies a `429` refusal — a client can finally pace itself instead of discovering its limit by hitting it.
- **[POST /hyperplanning](/v6/en/hyperplanning)** is **deprecated**: it keeps working on every version, but `v6` no longer lists it among its available endpoints. It will be removed for good in `7.0.0`.

## Documentation

- Added the **v6** documentation, in English and French, with its own sidebar, version switcher entry and changelog.
- Rewrote the pages of the four endpoints whose method or path changed, each carrying a callout explaining what moved and why.
- Documented the new rate limit headers on the **[Authentication](/v6/en/authentication)** page, and flagged the `status` type change on **[Getting Started](/v6/en/)**.
- Sidebar and Playground no longer offer `PATCH` or `DELETE` anywhere in v6, and the endpoint registry now describes per-version differences so v4 and v5 keep showing their own methods.
- Pages for `v1`, `v2` and `v3` now carry a banner stating the API no longer serves them.
- Moved the paid plans to Patreon and updated their prices.
