# 4.7.0

## API

**[API v4.7.0](https://github.com/moxondev/api/releases/tag/4.7.0)** — Address, Password, Token.

- Added endpoint **[GET /address](/v4/en/address)**: generates 1–10 fictional postal addresses for `fr`, `us`, `uk`, `de`, or `es` (random if omitted). Each address includes `street`, `city`, `zip`, `state`, `country`, and `countryCode`. Zip codes are formatted per country conventions.
- Added endpoint **[GET /password](/v4/en/password)**: generates 1–20 passwords using `crypto.randomInt`. Two modes: `random` (character-based, 8–128 chars) with configurable character sets (`uppercase`, `lowercase`, `digits`, `symbols`, `exclude`) and `passphrase` (word-based, 3–10 words, custom `separator`). Response includes `strength` (`weak` / `moderate` / `strong` / `very_strong`) and Shannon `entropy` in bits.
- Fixed **[POST /token](/v4/en/token)**: replaced `Math.random()` with `crypto.randomInt` for all character-based types, and fixed a truncation bug that silently shortened UUID tokens above a certain length.
- **[GET /personal](/v4/en/personal)** now delegates address generation to the `address` module, eliminating duplicated data generation logic.

- Added all 5 new endpoints — **[Address](/v4/en/address)**, **[Agent](/v4/en/agent)**, **[IP](/v4/en/ip)**, **[Headers](/v4/en/headers)** and **[Password](/v4/en/password)** — to the **Playground** registry and sidebar.
