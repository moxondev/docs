# 4.7.0

## API

**[API v4.7.0](https://github.com/moxondev/api/releases/tag/4.7.0)** — Address, Password, Token.

- Ajout de l'endpoint **[GET /address](/v4/fr/address)** : génère 1 à 10 adresses postales fictives pour `fr`, `us`, `uk`, `de` ou `es` (aléatoire si omis). Chaque adresse contient `street`, `city`, `zip`, `state`, `country` et `countryCode`. Les codes postaux sont formatés selon les conventions du pays.
- Ajout de l'endpoint **[GET /password](/v4/fr/password)** : génère 1 à 20 mots de passe via `crypto.randomInt`. Deux modes : `random` (basé sur des caractères, 8–128 caractères) avec jeux de caractères configurables (`uppercase`, `lowercase`, `digits`, `symbols`, `exclude`) et `passphrase` (basé sur des mots, 3–10 mots, `separator` personnalisable). La réponse inclut un niveau `strength` (`weak` / `moderate` / `strong` / `very_strong`) et l'entropie de Shannon `entropy` en bits.
- Correction de **[POST /token](/v4/fr/token)** : remplacement de `Math.random()` par `crypto.randomInt` pour tous les types basés sur des caractères, et correction d'un bug de troncature qui raccourcissait silencieusement les tokens UUID au-delà d'une certaine longueur.
- **[GET /personal](/v4/fr/personal)** délègue désormais la génération d'adresse au module `address`, supprimant la logique de génération de données dupliquée.
