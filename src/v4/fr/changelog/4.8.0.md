# 4.8.0

## API

**[API v4.8.0](https://github.com/moxondev/api/releases/tag/4.8.0)** — Cron, Regex, Countdown.

- Ajout de l'endpoint **[GET /cron](/v4/fr/cron)** : analyse une expression cron à 5 champs (`minute heure dom mois dow`) et retourne une description lisible ainsi que les prochains timestamps d'exécution. Support des fuseaux horaires IANA et d'un paramètre `from` pour définir le point de départ du calcul.
- Ajout de l'endpoint **[GET /regex](/v4/fr/regex)** : teste un pattern regex contre une chaîne de texte et retourne toutes les correspondances avec leur index, leurs groupes capturants numérotés et leurs groupes nommés. Support des flags `i`, `m`, `s` et `u` (le flag `g` est toujours appliqué).
- **[GET /time](/v4/fr/time)** accepte désormais `type=countdown` : calcule la différence entre maintenant et une date cible fournie via le paramètre `target`.
- Normalisation des constantes de niveau module en `UPPER_CASE` dans les modules v4.
