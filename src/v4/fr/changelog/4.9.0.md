# 4.9.0

## API

**[API v4.9.0](https://github.com/moxondev/api/releases/tag/4.9.0)** — Credit, Avatar, Barcode.

- Ajout de l'endpoint **[GET /credit](/v4/fr/credit)** : génère des numéros de cartes bancaires fictifs Luhn-valides. Supporte quatre marques (`visa`, `mastercard`, `amex`, `discover`) avec les préfixes IIN corrects, un paramètre `count` (1–10) et un paramètre `format` (`full` ou `masked`). Retourne le numéro de carte, le numéro formaté, la marque, la date d'expiration et le CVV.
- Ajout de l'endpoint **[GET /avatar](/v4/fr/avatar)** : génère des images d'avatars déterministes à partir d'une chaîne seed. Supporte deux types (`identicon` avec une grille symétrique 5×5, `pixel` avec une grille 8×8), la sortie en PNG et SVG, une taille configurable (50–2000 px) et une couleur de fond personnalisable.
- Ajout de l'endpoint **[GET /barcode](/v4/fr/barcode)** : génère des images de codes-barres à partir d'une chaîne de données. Supporte Code 128 (Set B), EAN-13, EAN-8, UPC-A et Code 39. Le chiffre de contrôle EAN est calculé automatiquement s'il est absent et validé s'il est fourni. Rendu en SVG (défaut) ou PNG.
- **[GET /personal](/v4/fr/personal)** utilise désormais le module `/credit` pour générer les données de carte : les numéros sont Luhn-valides, la longueur du CVV est cohérente avec la marque (4 chiffres pour Amex) et le numéro formaté utilise le bon espacement.
- **[GET /cron](/v4/fr/cron)** optimisé : les mois, jours et heures ne correspondant pas à l'expression cron sont désormais sautés directement, réduisant significativement le temps de calcul sur les expressions restrictives.
- Ajout du script `prepare` dans `package.json` : `tsc` s'exécute désormais automatiquement avant `npm publish`.
- Ajout de `.npmignore` : `src/`, `tests/`, les fichiers de configuration et les ressources de développement sont exclus du paquet npm publié.

## Documentation

- Ajout d'explications **"Comment ça marche"** sur **[Geo](/v4/fr/geo)** (formule de Haversine, distance orthodromique, cap) et **[Statistics](/v4/fr/statistics)** (formules populationnelles, égalités de mode, précision décimale).
- Suppression des encadrés de cas d'utilisation redondants sur **[Token](/v4/fr/token)**, **[Avatar](/v4/fr/avatar)** et **[Credit](/v4/fr/credit)**.
