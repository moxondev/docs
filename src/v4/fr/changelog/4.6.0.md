# 4.6.0

## API

**[API v4.6.0](https://github.com/moxondev/api/releases/tag/4.6.0)** — Agent, IP, Headers, sécurité.

- Ajout de l'endpoint **[GET /agent](/v4/fr/agent)** : analyse un User-Agent en métadonnées structurées — nom/version/majeure du navigateur, nom/version de l'OS, type/fabricant de l'appareil, nom/version du moteur de rendu, et un booléen `bot` pour les crawlers connus.
- Ajout de l'endpoint **[GET /ip](/v4/fr/ip)** : analyse une adresse IPv4 ou IPv6 et retourne sa version, son type (`public`, `private`, `loopback`, `link-local`, `multicast`, `broadcast`), sa classe (A–E, IPv4 uniquement), sa plage CIDR, sa représentation binaire, sa valeur décimale (IPv4 uniquement) et sa notation DNS inversé.
- Ajout de l'endpoint **[GET /headers](/v4/fr/headers)** : retourne les en-têtes HTTP de la requête sous forme de map clé-valeur, avec un paramètre `filter` optionnel (noms séparés par des virgules) et masquage automatique de `authorization`, `cookie`, `set-cookie` et `proxy-authorization`.
- Ajout de la documentation **JSDoc** sur toutes les fonctions exportées des modules v4.
- Ajout du tri automatique des imports via **`eslint-plugin-simple-import-sort`**.
- Correction de la vulnérabilité **[GHSA-w5hq-g745-h8pq](https://github.com/advisories/GHSA-w5hq-g745-h8pq)** dans la dépendance `uuid` (mise à jour vers v14).

## Documentation

- Ajout du paramètre requis `session` dans le panel **[POST /chat](/v4/fr/chat)**.
- Ajout de l'option `true` au paramètre `avatar` dans le panel **[GET /placeholder](/v4/fr/placeholder)**.
- Ajout des options de fuseau horaire en dropdown dans le panel **[GET /time](/v4/fr/time)**.
- Le bouton **Envoyer** des panels Try est désormais désactivé tant que tous les paramètres requis ne sont pas remplis.
- Les panels Try résolvent désormais leur configuration depuis un registre d'endpoints centralisé plutôt que via des props inline.
- Correction du footer recouvert par le sommaire **Sur cette page**.
